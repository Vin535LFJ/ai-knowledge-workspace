# 运动学与雅可比奇异（平面两连杆最小核）

> 支撑课：embodied-loop-journey L4。源提取自 Robot_Learn kb:5.16.1–3（verified 块，只读）；**全部算例经 Engine 独立复算（含 JᵀF 与奇异速度放大，py -3 逐条重推）**。断言 open/low，升级待 G1。
> 约定声明（源逐字）："机器人学里的符号约定各家不同，本节统一用最简的平面两连杆版本"。本文沿用：L1=0.4 m、L2=0.3 m，θ1 基座关节、θ2 肘关节（相对角）。

## 1. 正运动学：关节角 → 末端位置

$$x = L_1 \cos\theta_1 + L_2 \cos(\theta_1+\theta_2), \qquad y = L_1 \sin\theta_1 + L_2 \sin(\theta_1+\theta_2)$$

可达域是圆环：最远 L1+L2 = 0.70 m，最近 |L1−L2| = 0.10 m。

算例（θ1=30°、θ2=60°）：x = 0.4×0.8660 + 0.3×0 = **0.3464 m**；y = 0.4×0.5 + 0.3×1 = **0.5000 m**；距离 √0.37 = **0.6083 m**（在圆环内）。θ2=0 → 0.70 m；θ2=180° → 0.10 m。（kb:5.16.1，独立复算 OK）

## 2. 逆运动学：末端目标 → 关节角，无解是合法结论

$$\cos\theta_2 = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2}, \qquad \theta_1 = \operatorname{atan2}(y, x) - \operatorname{atan2}(L_2 \sin\theta_2,\; L_1 + L_2 \cos\theta_2)$$

可达判据：cosθ2 ∈ [−1, 1]。算例（目标 (0.60, 0.35)）：cosθ2 = 0.2325/0.24 = **0.96875** → θ2 = ±14.362°，两组解（肘向下 θ1=36.406°/θ2=−14.362°；肘向上 θ1=24.107°/θ2=+14.362°），代回均还原目标。不可达：(0.90, 0) → cosθ2 = 2.333 > 1；(0.02, 0) → cosθ2 = −1.040 < −1。（kb:5.16.2，独立复算 OK）

**无解时正确动作是"挂起并改目标"**，不是硬凑。（kb:5.16.2 纪律逐字）

## 3. 雅可比、力矩与奇异

$$\tau = J^{\mathsf T} F, \qquad \det J = L_1 L_2 \sin\theta_2$$

θ2 = 0 或 180° → detJ = 0 → J 不可逆 = **奇异位形**。

力矩算例（F = (0, −50) N，独立用 JᵀF 重推 OK）：

| 位形 | τ1 | τ2 | detJ |
|---|---|---|---|
| 伸直 (0°, 0°) | −35.0 N·m | −15.0 N·m | 0（奇异） |
| 收肘 (0°, 90°) | −20.0 N·m | 0 N·m | 0.12 |

同一个末端力，伸直位肩关节力矩是收肘位的 35/20 = **1.75 倍**。

**奇异附近速度放大**（末端水平向外 0.2 m/s，θ1=0，解 Jθ̇=v）：肘角 5° → θ2 转速 **765.7°/s**；45° → **82.7°/s**；90° → **38.2°/s**——5° 位与 90° 位相差约 **20 倍**。伸直位 J 两列水平分量都是 0：笔直向外的速度根本产生不出来，只能先弯肘。伸直位末端**向上** 0.2 m/s 有解：最小能量解 θ̇1=0.2414 rad/s（13.83°/s）、θ̇2=0.1034 rad/s（5.93°/s），校核 0.7×0.2414 + 0.3×0.1034 = 0.200 m/s。（kb:5.16.3，独立复算 OK）

## 4. 工程含义

- 奇异不是"算不出"，是"这个方向的速度/力传递失效"——规划要绕开奇异位形，控制要在奇异附近限速。
- 力矩账解释"为什么伸直指物费力"：力臂随位形变化，τ=JᵀF 把末端力映射回关节。
- 本最小核不覆盖：空间 6R/7R 逆解、动力学（M/C/G）、碰撞检测——首批边界如实声明。
