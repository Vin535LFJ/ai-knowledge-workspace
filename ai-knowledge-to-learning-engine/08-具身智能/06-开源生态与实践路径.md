# 开源生态与实践路径

> 支撑课：embodied-loop-journey L6。源提取自 Robot_Learn（只读）；算例经 Engine 独立复算；可复现性分层经 MuJoCo 官方文档核验。断言 open/low，升级待 G1。生态版本/状态为源快照（2026-11-12/14/17），引用须带快照日期。

## 1. 生态四组与起步三件

- **A 软件基础设施**：ROS 2 管通信与接口（本身不是具身大模型）、MoveIt 2 管机械臂（逆运动学/碰撞/轨迹）、Nav2 管移动底盘（导航/避障）——移动操作机器人三者同时出现。
- **B 仿真环境**：MuJoCo 偏通用物理与控制研究、Isaac Lab 偏 GPU 大规模训练、ManiSkill 偏操控任务与基准；能力有交集，**不需要一开始全装**。
- **C 模型与训练框架**：LeRobot / OpenVLA / openpi / Octo / GR00T。路线：先用 LeRobot 跑通采集–训练–评估，再选 VLA 深入研究。
- **D 数据集**：Open X-Embodiment（跨平台汇总）/ DROID（真实多样操作）/ ALOHA（低成本真机示范采集）/ Cosmos（世界模型数据与模型体系）。

**起步三件（桌面操控主线）：ROS 2 + MuJoCo + LeRobot**（通信、物理、学习各一件），ManiSkill/Isaac Lab 第 3–4 周再按任务加入。（textbook §10 L876；openlab L142–143/L182/L207–208）

**许可红线**：代码、权重、数据集、仿真资产可能用不同许可，**能下载不代表能商用**，逐项核对（例：gsplat Apache-2.0 可选，Inria 原 3DGS 实现研究许可不可商用；四大驾驶数据集全部非商业或专有）。（textbook L904/L940；openlab L175–177）

## 2. 十六周路线：第一个交付物是可复现，不是模型

每周 8–12 小时 × 16 周 = **128–192 小时**（投入多可压到 8–10 周）；每阶段有可验收标准，至少一半时间动手。（textbook L877/L910；openlab L333，独立复算 OK）

关键周验收（openlab L350–367 逐字要点）：

| 周 | 验收 |
|---|---|
| 0 | 代码能从干净环境按 README 重跑 |
| 4 | 有可重复的成功率，而不只展示一段成功视频 |
| 5 | 验证集与测试集分开，能报告失败案例 |
| 10 | 不把"模型能加载"当"机器人能执行"，给出定量评估 |
| 13 | 多次运行统计成功率，失败后重新观测而不是盲目重放 |
| 15–16 | 第三方能按报告复现主要结果 |

评测两条硬要求：成功判定写成**可执行规则**；报告**试验次数与初始条件分布**——"同一初始条件重复 100 次不构成 100 个独立样本"。（textbook L916–917；openlab）

## 3. 可复现性分层（官方文档核验）

- **CPU MuJoCo**：官方声明逐位可复现，附三个警告——保存全部积分状态（warmstart 加速度位级相等）；接触事件 Lyapunov 指数高（混沌放大）；仅同版本同架构内成立。
- **GPU MJWarp**：官方 FAQ 逐字（2026-11-24 核验，google-deepmind/mujoco doc/mjwarp/index.rst）："Is MJWarp on GPU deterministic? **No.** …characteristic of non-deterministic atomic operations on GPU. Set device to CPU with `wp.set_device('cpu')` for deterministic results."
- **精度差异**：MJWarp float32 vs MuJoCo float64，求解器设置/碰撞/小摩擦值对浮点表示敏感（官方 FAQ 同节）。
- 源引 PR #1422（2026-11-11 合并）正文明言 "This does not guarantee complete stepping determinism"——GPU 确定性改进不改变"默认非确定"结论。

（textbook L647–655；principles ch3 L193–195；openlab L181；源 fact:72/73——**源登记缺口已列入勘误队列 #3**）

## 4. 本机 8GB 边界（源快照 2026-11-14，本机未复测）

官方端到端显存表（A100、624×416、含权重与全部推理缓冲）：VGGT-Ω 1 帧 6.02 GB、25 帧 7.80 GB → 7.80/8 = **97.5%**（边缘档待本机实测）；边际 (7.80−6.02)/24 ≈ **0.0742 GB/帧**。可行：AVM 拼接、3D bowl、gsplat 小场景离线；不可行：流式实时重建、生成式世界模型（Cosmos3-Nano 已 16B、Genie 3 闭源无权重）。旧"≤20 帧约 5.58 GB"为仅特征骨干口径，**已作废**；8GB 可行性不得跨 GPU 外推。（textbook L921–940，独立复算 OK；转引口径，本机未复测）

## 5. 九条坑（源逐字要点）

只看演示视频 / 把语言理解当行动能力 / 把仿真成功当真实成功 / 忽略动作空间 / 数据泄漏 / 一次引入太多组件 / 忽略推理延迟 / 混淆开放与可商用 / 盲目升级依赖。（textbook L919；openlab L459–467）

动作接口铁律：关节位置/关节速度/末端位姿/夹爪开合/动作 token 互不兼容，换接口权重未必能用。（openlab L209）
