# 运动学与雅可比奇异

> **本章回答**：机械臂伸直时为什么够得着却动不了？
> **写作纪律**：正文重组课源的关键推导与算例，权威表述链接课源锚点；本课全部算例（正运动学、逆运动学、JᵀF、奇异速度放大）经 Engine 用 Python 逐条独立重推；本课断言写作时均为 open/low。符号约定沿用课源：L1 = 0.4 m、L2 = 0.3 m，θ1 为基座关节角，θ2 为肘关节相对角。
> **路线位置**：embodied-loop-journey 第 4 课（E01 → E02 → E03 → **E04** → E05 → E06），建议 55 分钟；无绑定交互实验，练习为纸面手算。
> **学习目标**（完成本章后你应能）：① 手算平面两连杆的正运动学与逆运动学 ② 用 cosθ2 判断目标是否可达 ③ 解释雅可比奇异对力矩与速度的影响——前置概念见 [E03 时空对齐与标定](E03-时空对齐与标定.md)。

## 1. 从一个问题开始

把你的手臂完全伸直，然后用指尖"笔直地再往外顶一点"。做不到——手指已经在最远处了。但如果让你**往上**抬，马上就能动。

同一个位形，一个方向动不了，另一个方向随便动。这不是肌肉的问题，是几何的问题。机械臂完全一样：**伸直位**是它最远也最"僵"的位形。

这一课用最简单的平面两连杆机械臂，把三件事手算一遍：**关节角怎么变成末端位置、末端目标怎么反解关节角、为什么某些位形下某个方向的速度产生不出来**。

## 2. 学习前提

- **E03**：坐标系与外参——知道"一个点在不同坐标系里有不同的坐标"。
- 数学：三角函数、atan2（已知 y 与 x 求角度）、2×2 矩阵的乘法与行列式。

四个首次出现的术语，先给一句话解释：

- **正运动学**（Forward Kinematics）：已知关节角，算末端在哪。
- **逆运动学**（Inverse Kinematics）：已知末端要去哪，反解关节角。
- **雅可比矩阵**：把关节速度映射成末端速度的矩阵；它的转置把末端力映射回关节力矩。
- **奇异位形**：雅可比矩阵不可逆的位形——某个方向上的速度或力传递失效。

## 3. 直观认识

把两连杆想成**两节胳膊**：肩膀转 θ1，肘弯 θ2。

- 肘伸直，指尖画出一个**大圆**（半径 = 两节之和）。
- 肘完全折回，指尖贴到离肩膀最近的地方，画出一个**小圆**（半径 = 两节之差）。
- 介于两者之间，指尖能到达的是两圆之间的**圆环**。

胳膊再怎么转，指尖也到不了圆环外面，也到不了小圆里面——这是几何定死的，不是控制算法能改的。

> **类比的边界**：胳膊类比帮记住"可达域是圆环"，但它给不出**奇异**的直觉。伸直位不只是"到头了"，而是**沿半径方向的速度产生不出来**——再快的关节转速也换不来指尖向外的速度。这个方向性只有通过雅可比矩阵才看得清，是 §4.3 的内容；类比到"可达域"为止。

## 4. 一步一步理解原理

### 4.1 正运动学：关节角 → 末端位置

两连杆末端位置（[课源 §1](../../../08-具身智能/04-运动学与雅可比奇异.md#1-正运动学关节角-末端位置)，断言 `V75`）：

$$
x = L_1\cos\theta_1 + L_2\cos(\theta_1+\theta_2), \qquad y = L_1\sin\theta_1 + L_2\sin(\theta_1+\theta_2)
$$

**可达域是圆环**：最远 L1 + L2 = 0.70 m，最近 |L1 − L2| = 0.10 m。

分行算例（θ1 = 30°、θ2 = 60°）：

| 步骤 | 运算 | 结果 |
|---|---|---|
| ① 第一节末端 | 0.4 × (cos 30°, sin 30°) | (0.3464, 0.2000) |
| ② 第二节相对角度 | θ1 + θ2 = 90° | 0.3 × (cos 90°, sin 90°) = (0, 0.3000) |
| ③ 相加 | ① + ② | **(0.3464, 0.5000) m** |
| ④ 距基座距离 | √(0.3464² + 0.5000²) = √0.37 | **0.6083 m**（在圆环内） |

两个边界位形：θ2 = 0 → 0.70 m（最远）；θ2 = 180° → 0.10 m（最近）。

### 4.2 逆运动学：末端目标 → 关节角，无解是合法结论

反解公式（[课源 §2](../../../08-具身智能/04-运动学与雅可比奇异.md#2-逆运动学末端目标-关节角无解是合法结论)，断言 `V76`）：

$$
\cos\theta_2 = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2}, \qquad \theta_1 = \operatorname{atan2}(y, x) - \operatorname{atan2}(L_2\sin\theta_2,\; L_1 + L_2\cos\theta_2)
$$

**可达判据：cosθ2 ∈ [−1, 1]。** 分行算例（目标 (0.60, 0.35)）：

| 步骤 | 运算 | 结果 |
|---|---|---|
| ① 目标距离平方 | 0.60² + 0.35² | 0.4825 |
| ② 减去两杆平方 | 0.4825 − 0.16 − 0.09 | 0.2325 |
| ③ 除以 2·L1·L2 | 0.2325 / 0.24 | **cosθ2 = 0.96875** ∈ [−1, 1]，可达 |
| ④ 反解 θ2 | arccos(0.96875) | **−14.362°（肘向上，见 ⑤）/ +14.362°（肘向下，见 ⑥）** |
| ⑤ 反解 θ1（肘向上） | 30.256° − (−6.150°) | θ1 = 36.406°，θ2 = −14.362° |
| ⑥ 反解 θ1（肘向下） | 30.256° − 6.150° | θ1 = 24.107°，θ2 = +14.362° |

"肘上 / 肘下"按**肘关节落在基座—腕连线的上方还是下方**命名，不按 θ2 的正负。代入验算：⑤ 组肘关节在 (0.3219, 0.2374)，高于该处连线（y = 0.1878），是肘向上；⑥ 组肘关节在 (0.3651, 0.1634)，低于连线（y = 0.2130），是肘向下。

> **口径注记**：课源把这两组解的"肘上 / 肘下"标签写反了（错误源自 Robot_Learn 原文，只读不改，已登记勘误：见 `reviews/embodied-batch1/independent-review.md`）；本课按通行定义标注。

两组解代回正运动学都能还原目标。再看两个**不可达**的目标：

| 目标 | cosθ2 | 结论 |
|---|---|---|
| (0.90, 0) | 2.333 > 1 | 太远，超出圆环外沿 |
| (0.02, 0) | −1.040 < −1 | 太近，落在圆环内沿以内 |

课源的纪律只有一句：**无解时正确动作是"挂起并改目标"，不是硬凑。** 把 2.333 截成 1 去算，你会得到一个"看起来合法"的关节角，但它指向的根本不是你要去的地方。

### 4.3 雅可比、力矩与奇异

雅可比矩阵把关节速度映射到末端速度；它的转置把末端力映射回关节力矩（[课源 §3](../../../08-具身智能/04-运动学与雅可比奇异.md#3-雅可比力矩与奇异)，断言 `V77`）。对平面两连杆：

$$
J = \begin{bmatrix} -L_1\sin\theta_1 - L_2\sin(\theta_1+\theta_2) & -L_2\sin(\theta_1+\theta_2) \\ L_1\cos\theta_1 + L_2\cos(\theta_1+\theta_2) & L_2\cos(\theta_1+\theta_2) \end{bmatrix}
$$

它的行列式有一个极简的形式：

$$
\det J = L_1 L_2 \sin\theta_2, \qquad \tau = J^{\mathsf{T}} F
$$

**θ2 = 0° 或 180° → detJ = 0 → J 不可逆 = 奇异位形。** 下面有两笔账，第一笔与奇异无关、但常被当成奇异来讲；第二笔才是奇异真正的后果。

**第一笔（力矩账，对比项）：同一个末端力，关节力矩随位形变化。** 算例 F = (0, −50) N（向下的力）：

| 位形 | J | τ = JᵀF | detJ |
|---|---|---|---|
| 伸直 (0°, 0°) | [[0, 0], [0.7, 0.3]] | **(−35.0, −15.0) N·m** | 0（奇异） |
| 收肘 (0°, 90°) | [[−0.3, −0.3], [0.4, 0]] | **(−20.0, 0) N·m** | 0.12 |

伸直位肩关节力矩是收肘位的 35 / 20 = **1.75 倍**——这个比值正好等于两个力臂之比 0.7 / 0.4，原因是力臂变长，与伸直位是否奇异无关。它是"伸直持重更费劲"的数学版本。

**第二笔（奇异的后果）：沿臂方向的速度传递失效，奇异附近速度放大。** 要让末端以 0.2 m/s 水平向外运动（θ1 = 0），解 J·θ̇ = v：

| 肘角 θ2 | 所需 θ2 转速（幅值） | detJ |
|---|---|---|
| 5° | **765.7°/s** | 0.0105 |
| 45° | 82.7°/s | 0.0849 |
| 90° | **38.2°/s** | 0.12 |

肘角越接近 0，同样的末端速度要求的关节转速越大——5° 位是 90° 位的约 **20 倍**；到了 0°，伸直位的 J 第一行全是 0，**笔直向外的速度根本产生不出来**，只能先弯肘。力的方向同理：伸直位沿臂方向的末端力**不受关节力矩控制**——沿臂方向的外力乘 Jᵀ 得到的关节力矩为零（Jᵀ 乘 (1, 0) 得零），关节力矩既对抗不了它，也调节不了它。而同一伸直位下，末端**向上** 0.2 m/s 是有解的（解不唯一，肘关节有多种转法都给出这个向上速度）。

### 4.4 工程含义

- 奇异不是"算不出"，是"沿某些方向的速度 / 力传递失效"——规划要绕开奇异位形，控制要在奇异附近限速。
- 力矩账解释"为什么伸直持重费力"：力臂随位形变化，τ = JᵀF 把末端力映射回关节。这笔账与奇异无关，别混为一谈。
- 本课只是最小核：不覆盖空间 6R / 7R 逆解、动力学、碰撞检测。

## 5. 反例与易错点

| 易错做法 | 问题在哪 | 正确做法 |
|---|---|---|
| 逆解 cosθ2 越界时截到 [−1, 1] 硬算 | 得到的关节角指向别处 | 无解是合法结论：挂起并改目标 |
| 忘记逆解有两组解 | 肘上 / 肘下都能到，但路径不同 | 两组都算，按场景选 |
| 把奇异当"到达极限" | 奇异是方向性的 | 看雅可比：沿某些方向的速度产生不出来 |
| 把"伸直持重更费劲"当成奇异后果 | 力矩比等于力臂比，与 detJ 无关 | 奇异的后果是沿臂方向速度 / 力传递失效 |
| 在伸直位附近仍按额定速度规划 | 关节转速被放大数十倍 | 奇异附近限速或绕开 |
| 认为可达域是整个圆盘 | 忽略圆环内沿 | 可达域是圆环：|L1 − L2| ≤ 距离 ≤ L1 + L2 |

## 6. 动手练习

每题给出"做什么 → 预期 → 机制"。

**练习 1 · 正运动学**
L1 = 0.4 m、L2 = 0.3 m，θ1 = 0°、θ2 = 90°。末端在哪？距基座多远？在可达域内吗？
预期：x = 0.4 + 0.3 × cos 90° = **0.4 m**；y = 0 + 0.3 × sin 90° = **0.3 m**；距离 √(0.16 + 0.09) = **0.5 m**，在 0.10–0.70 m 圆环内。
机制：两节向量首尾相接，末端坐标是两节向量之和。

**练习 2 · 逆运动学与可达性**
目标 (0.5, 0.2)。可达吗？若可达，求 θ2。
预期：cosθ2 = (0.25 + 0.04 − 0.25) / 0.24 = **0.1667**，可达；θ2 = ±80.4°。
机制：可达判据 cosθ2 ∈ [−1, 1]，越界即无解。

**练习 3 · 无解处置**
目标 (0.8, 0)。cosθ2 是多少？应该怎么做？
预期：cosθ2 = (0.64 − 0.25) / 0.24 = **1.625 > 1**，不可达；正确动作是挂起并改目标。
机制：目标超出可达域外沿 0.70 m。

**练习 4 · 力矩与奇异**
F = (0, −40) N，比较伸直位与收肘位的肩关节力矩。
预期：伸直位 τ = (0.7 × (−40), 0.3 × (−40)) = **(−28, −12) N·m**；收肘位 τ = **(−16, 0) N·m**；比值仍是 1.75 倍。
机制：τ = JᵀF，J 只取决于位形，力矩比与力的大小无关。
