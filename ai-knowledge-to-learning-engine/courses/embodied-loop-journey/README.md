## 六课路线

```
U1 判据与闭环   E01 闭环判据与错误落点 → E02 六环闭环与时间预算
U2 对齐与运动学 E03 时空对齐与标定 → E04 运动学与雅可比奇异
U3 学习与落地   E05 模仿学习复合误差与 Sim2Real → E06 开源生态与实践路径
```

一条线：先确认闭环真的闭合（E01），再算清每一轮花多少时间（E02），把时间误差变成毫米（E03），确认机械上到得了（E04），算清学出来的策略在长链上还剩多少成功率（E05），最后让这一切可以被别人复现（E06）。

每篇教材遵循 LXD 六项增强：本章回答 / 路线位置 / 学习目标条 / 学习前提（术语一句话）/ 直观认识（类比及其边界）/ 一步一步理解原理（分行推导表），并以反例、练习、自测、衔接收尾。
