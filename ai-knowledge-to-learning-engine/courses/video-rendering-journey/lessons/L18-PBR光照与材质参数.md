# PBR 光照与材质参数

> **本章回答**：为什么调三个参数就能得到从磨砂塑料到抛光金属的不同质感？
> **写作纪律**：正文用自己的语言展开推导，权威定义与完整细节链接主文档锚点；陌生术语首次出现给出一句话解释。
> **路线位置**：主课程 U7 第 2 课（prerequisites：L13、L14），建议 50 分钟，含动手实验（[PBR 光照与材质](#/lab/pbr-lighting)）。本课的 next 延伸至 [L19《HDR 视频渲染》](L19-HDR视频渲染.md)（主课程新终点）。

## 1. 从一个问题开始

L14 说过 PBR 是一组模型约束，Cook-Torrance 是主流实现。现在把实现拆开看。一个着色球，只动三个滑杆：

- roughness 0.1 → 0.9：高光从**锐利小点**变成**宽而暗的一片**；
- metalness 0 → 1：漫反射**消失**，反射带上了物体本身的颜色；
- 光源移到掠射角：边缘反射**显著增强**。

三个参数，三种质感变化——每一个都能从公式里推出来，而不是"调到好看"。这一章把 D/G/F 三项逐个拆开（断言 `V60`/`V61`），让你建立**参数 → 数学 → 画面**的完整直觉。这正是 Blinn-Phong 给不了的：它的高光强度没有物理单位，而 PBR 的 roughness 有明确含义——微表面法线分布宽度（L14 §4.1 的演进表在这里收口）。

## 2. 学习前提

- **L14**：PBR 模型约束与 BRDF 定位（`V46`）——本章是它的公式深潜。
- **L03/L14**：线性工作流——光照计算必须在线性空间（三条铁律），本章所有公式默认线性光强。
- **L13**：N·L、N·V 这些点积的几何意义——法线与光方向/视方向的夹角余弦。
- 术语先给一句话解释（PBR / BRDF / albedo / metalness / roughness / Fresnel / NDF / IBL 在 `tools/glossary.json` 有权威术语卡）：
  - **微表面模型**：把粗糙表面想象成无数微小镜面的集合，宏观反射是这些微面反射的统计结果。
  - **半角向量 H**：光方向 L 与视方向 V 的角平分线方向，`H = normalize(L+V)`——微面法线朝向 H 时恰好把光反射进眼睛。
  - **高光 lobe**：高光在方向空间里的"瓣"——越窄越锐利，越宽越弥散。

## 3. 直观认识

把表面想成一片**微型镜子海**：每面小镜子朝向略有不同。roughness 小 = 镜子几乎都朝同一方向（抛光金属），只有恰好对准半角的那批镜子把光送进眼睛——高光小而亮；roughness 大 = 镜子朝向乱七八糟（磨砂塑料），对准半角的镜子比例分散——高光宽而暗。**镜子总数没变，反射的总能量大致不变，变的只是分布**（断言 `V61`）。

> **类比的边界**：镜子海只覆盖镜面反射项 D 的直觉；漫反射是另一套机制（光进入材质内部散射后返回，§4.2），金属没有这套机制所以漫反射为零。类比也覆盖不了 G 项——微面之间还会互相遮挡阴影，不是每面朝向对的镜子都能贡献光（§4.1）。

## 4. 一步一步理解原理

### 4.1 Cook-Torrance 分解：D/G/F 各管什么（objective ①）

完整公式（[主文档 §3.1](../../../07-3D渲染与算法实现/光照材质与阴影.md#31-cook-torrance-分解)，断言 `V60`）：

$$
f_r = \underbrace{\frac{1-\mathrm{metallic}}{\pi} \cdot \mathrm{albedo}}_{\text{漫反射}} + \underbrace{\frac{D(h) \, G(l,v) \, F(v,h)}{4 (N\cdot L)(N\cdot V)}}_{\text{镜面反射}}
$$

| 项 | 作用 | 常用实现 |
|---|---|---|
| **D** | 微表面法线分布：多少微面朝向半角 | GGX / Trowbridge-Reitz |
| **G** | 几何遮蔽：微面互相遮挡 | Smith + Schlick-GGX |
| **F** | 菲涅尔：入射角越大反射越强 | Schlick 近似 |
| 分母 | 立体角与投影的归一化 | 4(N·L)(N·V) |

三项的分工一句话：**D 决定高光的形状，G 决定微面互相挡掉多少，F 决定反射随角度怎么变**。分母不是装饰——它是立体角与投影的归一化，漏掉它能量就不守恒。

### 4.2 metalness：漫反射与镜面的能量分配（objective ②）

看公式的漫反射项：系数是 `(1−metallic)/π`——**metallic=1 时漫反射恒为 0**（checkpoint ① 的答案）。物理原因（[主文档 §3.3 常见错误](../../../07-3D渲染与算法实现/光照材质与阴影.md#33-几何项与菲涅尔)与 [§10 Q2](../../../07-3D渲染与算法实现/光照材质与阴影.md#10-自测问答)）：金属的自由电子会吸收折射进入内部的光，透射光无法散射回来，只剩表面反射。给金属加漫反射，它看起来就像"发亮的塑料"——这是源文档点名的常见错误。

颜色去哪了？看菲涅尔的 F0（[§3.3 表](../../../07-3D渲染与算法实现/光照材质与阴影.md#33-几何项与菲涅尔)，断言 `V61`）：

| 材质 | F0 |
|---|---|
| 电介质（塑料、皮肤） | 约 0.04（4%） |
| 金属 | albedo 本身（0.5–1.0） |
| 混合工作流 | `F0 = mix(0.04, albedo, metallic)` |

**非金属的固有色来自漫反射（albedo），金属的固有色来自镜面反射的 F0**——同一个 albedo 参数，在两种材质里走完全不同的通道。工作流代码（源 §3.4 原文）：

```glsl
vec3 F0 = mix(vec3(0.04), albedo, metallic);
vec3 diffuseColor = albedo * (1.0 - metallic);
float alpha = roughness * roughness;
```

### 4.3 roughness → GGX lobe 宽窄（objective ③）

GGX 法线分布（[主文档 §3.2](../../../07-3D渲染与算法实现/光照材质与阴影.md#32-ggx-法线分布)，断言 `V61`）：

$$
D_{GGX}(h) = \frac{\alpha^2}{\pi \left((N\cdot H)^2(\alpha^2-1)+1\right)^2}, \qquad \alpha = \mathrm{roughness}^2
$$

逐步推（checkpoint ② 的答案）：

1. roughness 增大 → α = roughness² 增大；
2. α 增大 → 分母对 N·H 偏离 1 的惩罚变弱 → **D 分布变宽**（更多朝向的微面有贡献）；
3. 总能量大致守恒 → 分布变宽必然**峰值变矮** → 高光覆盖更大面积但更暗；
4. 画面表现：磨砂表面高光弥散，抛光表面高光锐利。

两个细节（源 §3.2 原文）：**α = roughness² 是 Epic 的工程约定** ✅——平方映射让低粗糙度区间变化更细腻（美术参数感知均匀）；N·H 接近 0 时 D 很小，避免高光从背面漏出。

G 项与 F 项的公式（源 §3.3，了解形状即可，实验里看效果）：Smith-Schlick-GGX 的 `k = (α+1)²/8`（直接光）或 `α²/2`（IBL）；Schlick 菲涅尔 `F = F0 + (1−F0)(1−V·H)^5`——**掠射角时 V·H 趋小，括号趋 1，F 趋 1**，反射比例显著增强（checkpoint ③ 的答案；实验 selfTest 用宏观 N·V 形式演示同一效应）。

### 4.4 能量守恒的补丁：多次散射

单次散射 BRDF 有个漏洞（[主文档 §3.5](../../../07-3D渲染与算法实现/光照材质与阴影.md#35-能量守恒与多次散射)，断言 `V62`）：粗糙度接近 1 时，高光被微面互相遮挡后**没有补回**——表现为"粗糙金属发黑"。工程补丁是 Fdez-Agüera 多项散射近似（Filament 的写法）：

$$
F_{ms} = F_{ss} \cdot \frac{F_{avg}}{1 - E_{ms} F_{avg}}, \qquad F_{avg} = F_0 + \frac{1-F_0}{21}, \qquad E_{ms} = 1 - F_{ss}
$$

符号含义（源 §3.5）：F_ss 是单次散射的菲涅尔项（IBL 中为 `F0·brdf.x + brdf.y`），E_ms 是单次散射能量，F_avg 是平均菲涅尔——把损失的能量按平均值补回，粗糙金属不再发黑。**这是近似，不是严格物理** ⚠️（源原文）；移动端常直接省略，用美术调参补偿。

## 5. 数学原理 / 数据形态

参数 → 数学 → 画面的完整对照（[主文档 §3.6 表](../../../07-3D渲染与算法实现/光照材质与阴影.md#36-参数如何改变画面交互实验)）：

| 参数 | 数学作用 | 画面表现 |
|---|---|---|
| 光源方向 | 改变 N·L 与半角 H | 高光位置移动 |
| 光强 | 整体缩放入射辐照度 | 明暗整体变化 |
| albedo | 漫反射系数 (1−metallic)·albedo/π | 非金属的固有色 |
| metallic | 漫反射↔镜面能量分配，F0 由 albedo 决定 | 金属失去漫反射、反射带颜色 |
| roughness | GGX 的 α = roughness² | 高光从锐利小点变宽而暗 |

数值算例（教学算例，公式用源 §3.2）：N·H = 1（正对半角）时 D = α²/(π·α⁴) = 1/(πα²)——roughness=0.1 → α=0.01 → D≈3183；roughness=0.5 → α=0.25 → D≈5.09。**峰值差约 625 倍**，而 lobe 宽度反向变化——这就是"宽而暗 vs 窄而亮"的定量版本（总能量**大致**守恒；高粗糙度存在单次散射损失，见 §4.4——单看 D 峰值不能算总能量）。

## 6. 工程应用与常见错误

**排查现场**（由源 §3.3/§3.5 重组的教学案例）：车模金属漆在粗糙度高的区域"发黑"。按 §4.4 机制倒推：单次散射 BRDF 高粗糙度能量损失 → 检查是否实现了多次散射补偿 → 补 Fdez-Agüera 近似（或移动端按源口径用美术调参补偿并说明）。另一个现场：金属看起来像"发亮的塑料" → 查 diffuseColor 是否漏乘 (1−metallic)（§4.2 源点名错误）。

常见误区：

- **"metallic 只是调反射强度。"** 它重新分配漫反射/镜面能量，并决定 F0 来源（`V61`，§4.2）。
- **"roughness 调高光亮度。"** 它调分布宽度；峰值变暗是能量守恒的结果不是目的（`V61`，§4.3）。
- **"PBR 参数调到好看就行。"** 参数有物理含义——这是 PBR 与 Blinn-Phong 的本质区别（`V46`，L14）。
- **"单次散射 BRDF 天然能量守恒。"** 高粗糙度有损失，需要多次散射近似补丁 ⚠️（`V62`，§4.4）。
- **"实验画面 = 物理精确渲染。"** 实验是教学近似/归一化示意（Canvas 2D 粗网格），不是离线渲染器（源 §3.6 ✅ 标注，§7）。

## 8. 总结与主动回忆

合上文档，复述这条因果链（说不出来就回到对应小节）：

**Cook-Torrance = 漫反射 (1−metallic)·albedo/π + 镜面 D·G·F/4(N·L)(N·V)：D 管形状、G 管遮蔽、F 管角度（`V60`）→ metallic=1 漫反射归零（自由电子吸收透射光），颜色改走 F0=albedo；非金属 F0≈0.04（`V61`）→ α=roughness²（Epic 约定），roughness 增大 → D 变宽变矮、总能量大致守恒 → 高光宽而暗（`V61`）→ 掠射角 V·H 趋小 F 趋 1，边缘反射增强 → 高粗糙度单次散射能量损失，Fdez-Agüera 近似补回 ⚠️（`V62`）→ 参数有物理含义，这是 PBR 约束的落地（`V46`）。**

再自问三个"为什么"：为什么分母 4(N·L)(N·V) 不能漏？为什么 α 取 roughness 的平方而不是直接用？为什么金属的固有色在 F0 而不在漫反射？
