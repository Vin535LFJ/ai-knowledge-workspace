# 学习设计说明 · embodied-loop-journey 六课（DESIGN 阶段产物）

> 关联：RUN-2026-11-23-embodied-batch1 · 课程契约 `courses/embodied-loop-journey/course.json` · Skill `.agent/skills/learning-experience-design/`
> **性质说明**：六课由上一写作窗口按 LXD 原则直接写成，没有先出设计稿。本说明是写作与审读完成后，按页面实测补记的设计记录——它描述页面上实际有什么，不是事前方案。表中每个数字都是 2026-11-25 用脚本对课文实测的结果。

## 1. 页面原型与课程结构

- 原型（按 LXD `learning-page-archetypes.md` 的七类）：E01、E06 偏 **B 系统教材**（概念与判据，无公式）；E02–E05 偏 **C 技术原理推导**（公式 + 分步算例）。
- 三个单元：U1 判据与闭环（E01、E02）→ U2 对齐与运动学（E03、E04）→ U3 学习与落地（E05、E06）。前置链 E01→E02→E03→E04→E05→E06，E05 另声明前置 E02。
- 每课建议时长 35–55 分钟（课程契约 `minutes`）。

## 2. LXD 六项最小增强的落实情况（实测）

- 每课正文都从一个反直觉问题开场（如"单步 95% 的策略 50 步成功率是多少"），并用"类比的边界"声明类比给不出的那一层。

## 3. 与主课程的连接（不另建课程系统）

- 术语：新增 `embodied-ai` 术语组 21 词，与主课程共用同一份 `tools/glossary.json`。
- 跨课程链接：课文指向主课程 L01、L02、L13、L15（同一条纪律的另一面），文件全部实存。
- 站点：六课以独立课程身份进入离线站（首页目录 7 个入口 + 全文搜索），没有新增站点功能。

## 4. 实践与交互设计

- **无绑定交互实验**：`tools/labs.json` 中具身实验 0 条，课程契约如实写明。练习为纸面手算与判断题，每题含"做什么 → 预期 → 机制"。
- 每课一份测验（`quizzes/E01–E06.json`），每题挂断言编号；§7 自测三题 = 课程契约 checkpoint = 测验前三题题干（独立审读已逐字比对）。
- E06 的自测第 1 题在整改中换成九条坑的判断题，以覆盖学习目标 3；代价是学习目标 1（生态四组）不再有检查点题，由练习 1 覆盖。

## 5. 质量门槛（Floor / Reflex / Finish）

| 门槛 | 做了什么 | 结果 |
|---|---|---|
| Floor 静态检查 | 六课分别执行 `check_visual_floor.py` | 六课 exit 0 |
| Floor 结构与构建 | `validate_site.py`、两门课程的 `check_chapter_arc.py` | 20/0/0；两门课程 0 FAIL |
| Floor 渲染 | Edge headless 打开 E02、E05、E06 文档页 | 标题、学习目标、公式、术语卡、证据面板正常；无归档横幅、无未渲染标记 |
| Floor 响应式 / 键盘 / 主题 | **未对这六页单独做** | 这六页沿用主课程教材页的同一套模板与样式，模板层此前已检查；按页面的多宽度、键盘、明暗主题检查没有做 |
| Reflex | 六课结构一致（同一页面原型）；未新增装饰、渐变或卡片堆叠 | 无需豁免项 |
| Finish | 不阻塞，未做 | — |

## 6. 已知局限（如实）

1. 学习站"教材模式"导航只展示主课程；具身课程从首页目录或搜索进入，课后检查点测验在界面上走不到。补一个课程切换入口属于站点功能改动，已登记 Program PARKING-LOT，等用户裁决。
2. 无交互实验，"实践与可验证性"弱于有实验的课。
3. V68–V87 共 20 条断言全部 open/low，证据链待 G1 裁决。
