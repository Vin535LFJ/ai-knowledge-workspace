# L19 学习设计说明（DESIGN 阶段产物）

> RUN-2026-11-20-p10-hdr · 依据 lesson-quality-standard 十维度与 L01 Gold Standard。

## 1. 认知路径设计

钩子（发灰现象 + 10000/1000/100 nit 数字张力）→ 前提唤起（L03 三字段/L12 合成链/L14 后处理顺序，各一句话复习）→ 类比（亮度货币：PQ 金本位/HLG 购买力/元数据报关单/TM 兑换窗口，**边界声明**：只覆盖亮度维，gamut mapping 独立）→ 四个核心机制按"编码→决策→传递→适配"因果顺序展开 → 全链图 + 丢失后果速查表（每行挂断言/前课）→ 排查现场（四步定位，每步有观测点）→ 练习（算例/读元数据/走查/位置决策）。

## 2. 表达方式选择（按知识类型）

| 知识类型 | 表达 | 理由 |
|---|---|---|
| PQ/HLG 对比 | 六维对比表 | 对比型知识，表格最省认知 |
| PQ EOTF | 公式三件套（符号/算例/后果）+ code 509 推导 | 数学型知识必须可复算；锚点双精度标注 |
| 元数据语义 | 三件套表 + 三条权威边界 | 定义型 + 易误解点前置 |
| Android 链路 | ASCII 链图 + 两个官方坑 | 数据流型知识用图；坑来自官方原话口径 |
| tone mapping | 等比 ÷4 反例（显式标注教学算例）+ 线性光推导 | 因果推导型；反例建立"为什么非线性" |
| 故障定位 | 速查表 + 四步排查现场 | 工程型知识给可复述现场 |

## 3. 交互与实验决策

**不新建 lab**：本章核心是"读曲线/读元数据/走查链路"，纸面算例 + 真实工具（colour-science/ffprobe）练习比新建交互实验更贴近工程现场；照 L10/L12 无绑定实验先例，路线位置显式声明。PBR/lathe 等既有实验不越界绑定。未来若做 HDR 交互实验（候选：PQ 曲线拖动 + tone mapping 算子对比），属 LXD 阶段（ROADMAP Next），不在本批。

## 4. 与既有课程的边界

- L03 §4.4 概览保留不动；L19 是其深潜（§4.1 显式注明 V23 边界修订走 G1，不擅改 L03/V23 文本）。
- L14 后处理顺序/tone mapping 定义不重复展开，用前提唤起 + 链接。
- L18 桥句联动改写（next 链终点转移），知识正文零改动。
- 数字纪律：nit 单位统一 cd/m² 口径；锚点精确值 + 舍入值双标注；教学算例显式标注；MB/MiB 类混淆不涉及。

## 5. 练习设计（PRACTICE 阶段依据）

四项练习各含"做什么→预期看到什么→对应哪个机制"（质量标准 §2.9）：① colour-science 复算锚点（可执行验证）② ffprobe 读真实元数据（真实工具）③ 发灰四步走查（故障定位能力）④ TM 位置决策（与 L14 联动）。checkpoint 3 题与 objectives 一一对应，§9 自我检测逐字一致；quiz 待 pilot 纳入后补建（L18 先例）。
